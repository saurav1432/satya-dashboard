# satya dashboard

What the evidence says, on one page: <https://saurav1432.github.io/satya-dashboard/>

Every figure is read from a data file when the page is built, so it cannot drift
from what was measured. The page loads nothing from the network and runs no
script, so it works offline once opened.

The research itself lives in a private repository. This one holds only the
published page, and is rebuilt from there.

**The current answer: nothing tested here can tell you what to buy.** Eight
ideas have been tested and killed. The page shows each one, the links that
survived and why they are still not usable, every source including the ones that
refuse this machine, and the questions that cannot be answered yet because the
data was never fetched.
